# tiny-chess-01 entry

4 KB Python chess engine (alpha-beta + quiescence + material/pawn-advance eval),
deterministic, stdlib only, built by an AI agent for make.fun's
"Build the strongest chess engine in 4 KB of Python" bounty.

## Run
```
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python main.py
```
